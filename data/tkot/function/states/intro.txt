TKOT 设计备忘
=====================================

【状态机 #steps（int 计分板）】
  0 = 大厅准备
  1 = 开场（5 秒倒计时标题；已取消冻结与黑屏）
  2 = 战斗
  3 = 结算 + 地图复位

【玩家身份 statu（dummy 计分板，唯一身份来源）】
  0 = 不在游戏（大厅）
  1 = 站在准备台上（唯一会被计入“准备”的状态）
  2 = 本局玩家·存活
  3 = 本局玩家·已淘汰（观战）
  4 = 非本局观战（大厅里的 / 中途加入的，一开战就被扯进场地）

  statu 是身份判定的唯一依据，判定一律用 @a[scores={statu=N}]。
  不再使用 on_game / alive / spectating / prepare 这些 tag。

【仍然保留的 tag】
  joined   已进过服（永久，用于一次性引导）
  in_arena 当前在场地包围盒内（每 tick 重算，位置状态而非身份）

【身份变化规则】
  1. 只有站上绿混凝土（statu=1）的人在开局那一刻会变成 statu=2，并绑定当前局号 round。
  2. 掉线重连：只有 round 等于当前 #round 才保留 2/3，旧局残留一律作废回 0。
  3. 死亡即淘汰：statu 2 → 3，转旁观并关在场地内。
  4. 战斗开始后，所有非本局玩家（0/1，含中途加入）→ statu=4，并在同一 tick 被
     mapN_spectate 的包围盒拉进场地；离开就会被拉回，全程不能回大厅。
  5. 回合结束统一回 0（states/reset）。

【边界（缩圈预留）】
  maps/mapN_spectate 里的包围盒就是“安全区”。
  statu=2 的人一旦离开包围盒 → 判死（mechanics/damage）。
  statu=3/4 的人一旦离开包围盒 → 拉回观战点。
  以后做缩圈 = 让这个包围盒随时间逐圈变小，判死逻辑不用改。

【关键分数】
  #steps      当前状态
  #round      累计局数
  #total_player   状态0=在线人数；状态2=本局人数(2~3)
  #alive_player   状态2=本局存活人数(2)
  #total_prepare  准备台上的人数(1)
  #map_num    当前选中的地图编号
  death       每名玩家本局死亡次数（deathCount）
